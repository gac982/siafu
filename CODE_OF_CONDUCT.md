# Code of Conduct

## Our pledge

We want Siafu to be a respectful, harassment-free project for everyone, regardless of experience, identity, background, or level of contribution.

## Expected behavior

- Be respectful and constructive in issues, reviews, and discussions.
- Assume good faith and focus on the technical problem.
- Give actionable feedback and accept it gracefully.
- Respect privacy: do not publish other people's data, credentials, or private infrastructure details.

## Unacceptable behavior

- Harassment, discrimination, insults, or personal attacks.
- Publishing private information without permission.
- Deliberately disruptive behavior, spam, or bad-faith security testing.
- Testing load against systems without authorization.

## Scope

This code applies to repository issues, pull requests, discussions, and any project space.

## Enforcement

Report concerns privately to the maintainers through the repository's private contact or security advisory channel. Maintainers may edit or remove comments, close contributions, or restrict participation when this code is violated. Reports will be handled as confidentially as practical.
